##  Overview

Maintaining focus during study sessions can be difficult when digital distractions are a click away. Many traditional app blockers rely on simple timers that are easy to bypass.

The **Task-Driven Focus App** enforces a **reward-based focus mechanism**. Instead of relying purely on willpower, it is designed to restrict access to target applications or websites until pre-defined, high-priority tasks are marked complete.

---

##  Core Features

* **Task Management Interface:** Create, track, and manage study goals for active sessions.
* **Completion Logic:** Validate task status before triggering focus rewards or session progression.
* **Session Tracking:** Dedicated focus interface designed to keep study sessions organized.
* **Minimalist UI/UX:** Clean, distraction-free interface built for quick navigation.
